# Handoff release 0.1.0-handoff.1

Prepared as a clean starting point for a public GitHub repository.

Included:

- strict new-SoC-family detection from Zephyr `soc.yml` history;
- guards against identifier renames and metadata-only family wrapping;
- a one-year first-run backfill and newest-first RSS output capped at 50;
- durable cursor, catalog, and complete accepted-item history;
- scheduled and manual GitHub Actions execution with GitHub Pages deployment;
- synthetic regression tests, public documentation, and collaboration policy.

The target GitHub organization's Actions, Pages, branch-protection, and custom
domain settings still require verification after import.
